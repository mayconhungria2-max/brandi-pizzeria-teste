# Brandi Pizzeria Launch

Crie um site completo, profissional, responsivo e visualmente sofisticado para a BRANDI PIZZERIE, uma pizzaria artesanal.

IMPORTANTE: use a imagem de referência fornecida pelo usuário como referência PRINCIPAL para a arquitetura visual, composição, proporções, hierarquia das informações e sensação estética.

NÃO faça um site genérico de pizzaria.
NÃO transforme o projeto em um layout moderno de restaurante com cards excessivamente arredondados, gradientes ou visual de aplicativo.
NÃO descaracterize a composição da referência.

A intenção é RECRIAR A MESMA LÓGICA VISUAL da referência, adaptando-a completamente para a identidade e o conteúdo real da Brandi Pizzerie.

1. IDENTIDADE DA MARCA

Nome:
BRANDI PIZZERIE

Use o logo fornecido pelo usuário como logo oficial.

A identidade visual deve partir principalmente destas cores:

Verde escuro profundo, inspirado no fundo do logo da Brandi

Vermelho vivo/italiano para CTAs e elementos de destaque

Branco

Off-white / creme para fundos

Preto ou verde muito escuro para textos

Pequenos detalhes em verde mais claro quando necessário

A estética deve transmitir:

pizzaria artesanal

tradição italiana

elegância

qualidade

gastronomia

ambiente acolhedor

sofisticação sem parecer excessivamente luxuoso

aparência editorial

fotografia gastronômica de alta qualidade

Use bastante espaço em branco.

Use títulos com uma fonte serifada elegante, com personalidade editorial/italiana.

Para textos menores, use uma fonte sans-serif limpa e moderna.

A combinação deve lembrar uma revista gastronômica italiana sofisticada.

2. ESTRUTURA GERAL

A página deve seguir esta ordem:

Header

Hero principal

Introdução / proposta da pizzaria

Nosso Cardápio

Pizzas em destaque

Banner de pedido online

Informações de salão e delivery

Bebidas

Avaliações

Localização / contato

Footer

A página deve ser longa, elegante e com ritmo visual.

Não colocar tudo em uma única seção de cards.
